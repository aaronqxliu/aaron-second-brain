# High-Retention Script Generator

请严格读取 `20_Knowledge_Atlas/` 下的指定研报，并根据以下一致性结构输出脚本。

## 前置检查

1. 读取 `USER.md`，加载语调禁用词列表和 Compliance 规则。
2. 读取 `MEMORY.md`，确认脚本生成偏好。
3. 定位 `20_Knowledge_Atlas/` 下最新的或用户指定的深度研报文件。

## 1. 脚本时长与语调限制

| 约束项 | 要求 |
|--------|------|
| 总时长 | 5-8 分钟（严禁超过 8 分钟） |
| 字数上限 | ~1800 汉字（按 225 字/分钟语速） |
| 语调 | 沉稳、平实、娓娓道来 |
| 禁用词 | 参见 USER.md Compliance 中的 Prohibited words |
| 人称 | 第一人称，但开头不做自我介绍 |

## 2. 视频三段论结构模板

### 🎬 第一幕：痛点起笔 (0:00 - 0:45) — Hook

- 直接用一个**反直觉的商业悖论或数据**开场。
- 格式示例：
  > "一家只有 XX 人的公司，年营收做到了 XX 亿美元。它的人均创收是 Google 的 X 倍。这个数字背后藏着一个 AI 时代最重要的商业公式。"
- **绝对禁止**：
  - ❌ "大家好我是 Aaron..."
  - ❌ "今天我们来聊一聊..."
  - ❌ 任何形式的自我介绍或频道介绍

### 🎬 第二幕：降维解局 (0:45 - 5:30) — 核心论证

分两层账本递进拆解：

#### 层级 1: 工程账本 (~2 分钟)
- 用通俗类比解释技术架构（如何利用技术特性进行算力套利）。
- 必须包含至少一个**具体的工程细节**（不是空洞的"他们用了 AI"）。
- 视觉转场提示: `[画面：技术架构图 / 代码截图 / 架构对比图]`

#### 层级 2: 商业账本 (~2 分钟)
- 人效比、护城河、真实的 LTV/CAC 分析。
- 用 EREI 评分卡中的数据作为论据支撑。
- 视觉转场提示: `[画面：数据图表 / 财务数据可视化]`

### 🎬 第三幕：时代降噪 (5:30 - 7:00) — 利他启示

- 给国内出海老板或创业者的**可操作的商业启示**。
- 必须包含一个"降维应用"建议：将案例中的核心方法论抽象为可迁移的策略。
- 视觉转场提示: `[画面：总结要点 / 行动清单]`

### 🎬 片尾 (7:00 - 7:15)

固定 Slogan（逐字不变）：

> "我是 Aaron，在硅谷引擎舱，陪你冷眼看清 AI 的真实账本。我们下期三十六计见。"

- 视觉提示: `[画面：频道 Logo + 订阅引导]`
- BGM 节点: `[BGM: 片尾音乐渐入]`

## 3. 统一符号设计

在脚本中使用以下标记系统，方便后期剪辑团队识别：

| 标记 | 含义 |
|------|------|
| `[画面：...]` | 视觉转场/画面切换提示 |
| `[BGM: ...]` | 背景音乐变化节点 |
| `[数据卡片：...]` | 需要制作数据可视化卡片 |
| `[停顿 Xs]` | 刻意停顿，制造节奏感 |
| `[语调：↑]` / `[语调：↓]` | 语调变化提示 |

脚本生成后，Agent 必须自行完成以下检查，并在输出末尾附上检查结果：

- [ ] 总字数 ≤ 1800 汉字
- [ ] 无 USER.md 中的禁用词

- [ ] 所有 `[画面]` 标记均已填写
- [ ] Frontmatter 中 `published: false` 且 `privacy: true`
